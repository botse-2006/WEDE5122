# Velour & Vanilla Fragrance House

## Project Overview

Velour & Vanilla Fragrance House is a website designed to showcase a luxury fragrance brand. The website allows visitors to learn about the brand, explore its fragrance collection, and contact the business for enquiries.

## Website Pages

The website contains the following pages:

- **Home (`index.html`):** Introduces the brand and highlights its products.
- **About Us (`about.html`):** Provides information about the brand and its story.
- **Products (`products.html`):** Displays the fragrance collection.
- **Enquiry (`enquiry.html`):** Allows customers to enquire about products.
- **Contact (`contact.html`):** Provides a form for customers to send messages.

## Technologies Used

- HTML5 for website structure.
- CSS3 for styling and responsive layouts.
- JavaScript for interactive features and client-side form validation.

## Features

- Navigation between the website pages.
- Fragrance product displays.
- Interactive product filtering and product details, where implemented.
- Customer enquiry and contact forms.
- JavaScript form validation and feedback.
- Page-specific SEO titles and meta descriptions.
- Responsive styling for different screen sizes.

## Running the Website

1. Download or clone the repository.
2. Keep the HTML files and the `css`, `js`, and `img` folders in their existing locations.
3. Open `index.html` in a web browser.
4. Navigate through the website using the navigation menu.

## Forms and Limitations

The contact and enquiry forms provide client-side validation and feedback. They do not send or save customer messages unless a backend or external form-handling service is configured.
